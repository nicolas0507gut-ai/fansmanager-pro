# FansManager Pro

Landing page premium y responsive para una agencia de gestión de creadoras.

## Tecnologías
- HTML5
- CSS3
- JavaScript Vanilla
- Google Fonts

## Estructura
```text
fansmanager-pro/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── assets/
│   └── images/
└── README.md
```

## Cómo probar localmente
Abre `index.html` en tu navegador.

También puedes usar VS Code + Live Server.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube todos los archivos manteniendo la misma estructura.
3. Ve a:
   Settings → Pages
4. En "Build and deployment":
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
5. Guarda los cambios.

GitHub te mostrará la URL pública cuando termine el despliegue.

## Publicar en Netlify
1. Entra a Netlify.
2. Arrastra la carpeta del proyecto o conecta tu repositorio.
3. No necesitas comando de build.
4. Directorio de publicación: raíz del proyecto.

## Publicar en Vercel
1. Importa el repositorio de GitHub.
2. Framework preset: Other.
3. No necesitas build command.
4. Output directory: dejar vacío.
